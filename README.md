## Summary

PokémonExplorer is an Android app that uses the PokéAPI to retrieve and display information about different Pokémon. The app displays a Pokémon’s name, height, weight, and Pokédex number. Users can press the “Next Pokémon” button to retrieve and display a new Pokémon.
