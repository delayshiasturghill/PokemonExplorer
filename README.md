Summary
PokémonExplorer is an Android application that allows users to explore different Pokémon and view information about them, including their names, heights, weights, and Pokédex numbers.
I created this project using Kotlin and Android Studio. I practiced working with XML layouts, TextViews, RecyclerView, adapters, and styling to create a Pokémon-themed application.
If I had to describe this project in three emojis, they would be: 🎮 🔍 💜
Application Features
The following features are implemented:
	☑	Display Pokémon names and information
	☑	Show Pokémon height and weight
	☑	Display a scrollable Pokémon list
	☑	Include a Next Pokémon button
	☑	Customize the layout with purple colors and styling
