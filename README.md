AND101 Project 5 - Choose Your Own API
Submitted by: Delayshia Sturghill
Time spent: 5 hours spent in total
Summary
PokémonExplorer is an Android application that uses the PokéAPI to retrieve and display information about different Pokémon. The app displays each Pokémon’s name, height, weight, and Pokédex number. Users can press the “Next Pokémon” button to retrieve and display information about another Pokémon.
This project helped me understand how Android applications communicate with APIs, retrieve information from the internet, and display that information to users.
If I had to describe this project in three (3) emojis, they would be: 🎮 🔍 ⚡

Notes
While completing this project, I learned how to connect an Android application to an external API using AsyncHTTPClient. I also practiced working with JSON responses, extracting information, and displaying it using TextViews.
One challenge I experienced was troubleshooting internet connectivity issues in the Android emulator, which initially prevented the app from retrieving Pokémon information. After working through the issue, I was able to successfully retrieve and display Pokémon data.
This project helped me become more comfortable using Android Studio, debugging problems, and understanding how APIs work in mobile applications.
